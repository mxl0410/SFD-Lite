# SFD-Lite Canonical v1

This namespace contains only the frozen, reproducible Phase 3 package. It does
not contain trained checkpoints or paper results. Historical F4/F0/SFD-X/
SFD-YOLO/UAVDT run04 artifacts remain outside this namespace and are not valid
canonical quantitative evidence.

The source snapshot is intentionally independent of the historical server. Run
the scripts under `scripts/sfd_lite_canonical` only after the data/evaluator
gates pass on an authenticated GPU server.
