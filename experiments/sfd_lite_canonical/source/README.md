# Modified Ultralytics source snapshot

This directory contains the complete Ultralytics 8.4.60 source snapshot used by
SFD-Lite-Canonical-v1. Install it from the repository root with:

```bash
python -m pip install -e ./experiments/sfd_lite_canonical/source
```

See the repository-level `README.md`, `NOTICE`, and `LICENSE` files for usage,
provenance, and licensing information.
